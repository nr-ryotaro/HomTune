# 間取り図機能の実装

## 実装した機能

### 1. 各部屋のデバイス数表示

間取り図の各部屋に、その部屋に配置されているデバイスの数をバッジで表示します。

- **表示位置**: 各部屋の右上
- **デザイン**: 青い円形バッジに白文字で数字を表示
- **自動更新**: デバイスが追加・削除されると自動的に更新

### 2. 部屋タップ機能

間取り図の部屋をタップ（クリック）すると、その部屋に配置されているデバイスのみを表示します。

- **タップ可能**: 各部屋の矩形領域全体がタップ可能
- **視覚的フィードバック**: 
  - ホバー時: 部屋の背景色が変わる
  - 選択時: 部屋がハイライト表示（青い枠線）
- **モバイル対応**: タッチイベントにも対応

### 3. フィルタリング機能

部屋をタップすると：

1. **デバイス一覧がフィルタリング**: 選択した部屋のデバイスのみ表示
2. **ヘッダー更新**: 「デバイス一覧 - [部屋名]」と表示
3. **部屋のハイライト**: 選択された部屋が視覚的に強調
4. **フィルタクリアボタン**: 「フィルタをクリア」ボタンが表示され、すべてのデバイスを再表示可能

## 使用方法

### 基本的な使い方

1. 間取り図で部屋をタップ
2. その部屋のデバイスのみが一覧に表示される
3. 「フィルタをクリア」ボタンで全デバイスを再表示

### モバイルでの操作

- タッチ操作で部屋をタップ
- タップ時の視覚的フィードバックあり

## 技術実装

### ファイル構成

- `src/js/floorPlan.js`: 間取り図のレンダリングと部屋クリック処理
- `src/js/app.js`: フィルタリングロジックと状態管理
- `src/js/ui.js`: デバイス一覧の表示更新
- `src/css/main.css`: 部屋クリック時のスタイル

### 主要な変更点

1. **FloorPlanRenderer クラス**
   - `getDeviceCountForRoom()`: 部屋のデバイス数を取得
   - `setOnRoomClick()`: 部屋クリック時のコールバック設定
   - デバイス数バッジの表示
   - 部屋のクリックイベント処理

2. **App クラス**
   - `filterDevicesByRoom()`: 部屋別フィルタリング
   - `highlightRoom()`: 選択部屋のハイライト
   - `clearRoomFilter()`: フィルタのクリア

3. **UI クラス**
   - `renderDeviceList()`: 部屋名を表示する機能を追加
