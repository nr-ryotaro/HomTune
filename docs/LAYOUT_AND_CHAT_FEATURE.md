# レイアウト変更とチャット機能の実装

## 実装内容

### 1. レイアウト順序の変更

新しいレイアウト順序：
1. **間取り図**（最上部）
2. **AIアシスタント（チャットBOX）**
3. **サマリーカード**（警告、メンテナンス予定、登録デバイス）
4. **デバイス一覧**

### 2. 間取り図のデザイン改善

不動産サイト風のデザインに変更：

- **グラデーション背景**: 上部を明るく、下部を暗くしたグラデーション効果
- **太めの枠線**: 1.0px（選択時2.0px）の太めの枠線
- **内側の影**: 立体感を出すための内側の影
- **部屋名のスタイル**: 太字（FontWeight.w600）、影付きテキスト
- **デバイス数バッジ**: 
  - 影付きバッジ（MaskFilter.blur）
  - 太めの白い枠線（2.0px）
  - より大きなフォントサイズ（11px）
- **デバイスアイコン**: 
  - 影付きアイコン
  - 白い枠線で強調
  - テキストに影を追加

### 3. AIアシスタント（チャット機能）

#### 機能概要

- **チャットインターフェース**: メッセージの送受信が可能
- **ダミーAI応答**: 現在はダミーデータで動作確認可能
- **デバイス情報の参照**: 登録されているデバイス情報を参照して応答

#### 対応プロンプト例

- 「リビングのエアコンの操作方法を教えて」
- 「MacBookの使い方を教えて」
- 「アンプのメンテナンス方法は？」

#### 応答内容

- デバイスの操作方法
- メンテナンス方法
- 公式マニュアルのURL
- トラブルシューティング情報

#### 将来の拡張

- 実際のLLM API（OpenAI、Claude等）との連携
- 公式サイトからの説明書PDF取得
- より詳細なコンテキスト理解

## 実装したファイル

- `lib/widgets/chat_widget.dart`: チャット機能の新規作成
- `lib/screens/home_screen.dart`: レイアウト順序の変更、チャットBOXの追加
- `lib/widgets/floor_plan_widget.dart`: 間取り図のデザイン改善

## 使用方法

1. 間取り図を確認（最上部に表示）
2. チャットBOXで質問を入力
3. AIアシスタントが回答を返す
4. サマリーカードで全体状況を確認
5. デバイス一覧で詳細を確認

## テスト方法

1. エミュレータを起動
2. `flutter run`でアプリを実行
3. チャットBOXで以下の質問を試す：
   - 「リビングのエアコンの操作方法を教えて」
   - 「MacBookの使い方を教えて」
   - 「アンプのメンテナンス方法は？」
