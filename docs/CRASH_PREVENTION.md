# クラッシュ防止の実装

## 実装した安全対策

### 1. グローバルエラーハンドリング

`lib/main.dart`:
- `FlutterError.onError`: Flutterエラーのハンドリング
- `PlatformDispatcher.instance.onError`: プラットフォームエラーのハンドリング
- `runZonedGuarded`: 未キャッチエラーのハンドリング

### 2. モデルパースの安全性向上

`lib/models/device.dart`:
- すべての`fromJson`メソッドにtry-catchを追加
- エラー時はデフォルト値を返す
- 型変換の安全性向上（`as num?`、`?.toString()`など）
- ネストされたオブジェクトのパースにもエラーハンドリング

### 3. データ読み込みの安全性向上

`lib/services/device_service.dart`:
- アセットファイル読み込み時のエラーハンドリング
- JSON解析時のエラーハンドリング
- 各データ構造の型チェック
- エラー時は空のデータを返す

### 4. UI描画の安全性向上

`lib/widgets/floor_plan_widget.dart`:
- サイズ検証（0以下の値をチェック）
- スケール計算の検証
- 各描画メソッドにtry-catchを追加
- 座標の検証（NaN、無限大をチェック）

### 5. 画面初期化の改善

`lib/screens/home_screen.dart`:
- mountedチェックの追加
- エラーハンドリングの改善
- 安全なカウント取得メソッドの追加

## エラーが発生してもクラッシュしない仕組み

1. **データパースエラー**: エラーが発生したデバイスはスキップされ、他のデバイスは正常に表示される
2. **描画エラー**: 個別の部屋やデバイスの描画エラーは無視され、他の部分は正常に描画される
3. **初期化エラー**: エラーが発生してもエラー画面が表示され、再試行が可能

## テスト方法

1. エミュレータを起動
2. `flutter run`でアプリを実行
3. アプリが正常に起動することを確認
4. ログを確認してエラーがないかチェック

## デバッグ方法

エラーが発生した場合、以下のコマンドでログを確認：

```powershell
flutter run --verbose
```

または、Android StudioのLogcatでエラーログを確認。
