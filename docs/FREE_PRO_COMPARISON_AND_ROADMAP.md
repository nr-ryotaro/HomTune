# Free / Pro 差異と今後の機能アイデア

## 現状のプラン差異（実装ベース）

| 項目 | Free | Pro |
|---|---|---|
| 月額 | 0円 | 490円 |
| 広告 | 下部バナー（ホーム・一覧のみ） | **なし** |
| スマートリモコン（Remo / SwitchBot） | 不可（ロック表示） | **連携・操作・チャット操作**（月300回） |
| 月間AIクレジット上限 | 40 | 120（自動調整対象） |
| 部屋画像生成 | **デフォルト or AI生成（実写なし）／Freeはアカウント生涯1回** | 2回/部屋/月（再生成可・最大10部屋） |
| AIチャット | クレジット範囲内 | クレジット範囲内 |
| スキャン補正/メンテ生成 | クレジット範囲内で利用可（枠は小） | クレジット範囲内で利用可（枠は大） |
| 上限超過時 | ローカル応答へフォールバック | ローカル応答へフォールバック + 追加購入導線（将来） |

## 実装上の制御ポイント

- `AiUsageService`
  - 月間クレジット、コスト上限判定
  - 部屋画像の Free/Pro 制限判定
- `BillingControlService`
  - 実請求ベースで翌月の Pro 上限を自動再計算
- `AiRoutingService`
  - ローカル回答優先でAI呼び出しを抑制

## 今後追加すべき機能アイデア（優先順）

1. **課金バックエンド連携（最優先）**
   - StoreKit / Play Billing 検証
   - サーバー側でプラン状態を正として判定
2. **追加クレジット購入**
   - 50 / 120 credits のパック課金
   - 購入時の即時反映
3. **原価ダッシュボード**
   - 実請求と推定コストの差分可視化
   - 機能別原価の時系列グラフ
4. **モデル自動切替**
   - 通常は `flash-lite`、高品質要求時のみ上位モデル
5. **AIキャッシュ**
   - 同一質問・同一文脈応答の再利用
   - 重複呼び出し削減
6. **運用アラート**
   - 原価率閾値超過で Slack / メール通知
7. **スマートリモコン連携**（実装済み MVP）
   - Nature Remo / SwitchBot プロキシ経由
   - 家電詳細のリモコン UI・チャット操作
8. **法人プラン（B2B）**
   - まとめ請求・席数管理・監査ログ強化

## 収益性をさらに上げる設計案

- Freeはローカル体験を強化し、AIは「価値を体験できる最小量」に固定
- Proは「時短価値」を明確化（画像再生成、高度診断、履歴比較）
- 高原価機能（画像生成）は段階課金に分離して粗利を守る
