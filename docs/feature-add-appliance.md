# 家電登録フロー機能

## 概要

「写真を撮るだけでAIが情報を補完し、最小限の手間で資産登録が完了する」という魔法のような登録体験を実現する機能です。

## アーキテクチャ

### ディレクトリ構成

```
lib/
├── screens/
│   └── add_device_screen.dart      # 登録画面（メイン）
├── widgets/
│   └── device_form.dart            # フォームコンポーネント
├── services/
│   ├── device_service.dart         # デバイス管理サービス（addDevice追加）
│   └── ocr_service.dart            # OCR解析サービス（モック）
└── models/
    └── device.dart                 # デバイスモデル
```

## データフロー

### 1. トリガー
- **メイン画面**: 間取り図の「家電を追加」ボタン
- **部屋詳細画面**: AppBarの「家電を追加」ボタン
- どちらも `AddDeviceScreen` を開く

### 2. AIスキャン・フェーズ

```
ユーザーが画像を選択
    ↓
OCRService.scanImage() が呼び出される
    ↓
「精密に調律中...」アニメーション表示
    ↓
モックOCR解析（2秒の遅延）
    ↓
解析結果をフォームに自動入力
```

**OCR解析結果（モック）:**
- `modelNumber`: 型番
- `manufacturer`: メーカー
- `name`: 製品名
- `category`: カテゴリ
- `serialNumber`: シリアル番号（任意）

### 3. フォーム入力・フェーズ

#### 必須項目（AIが自動入力を試みる）
- **型番 (Model Number)**: 説明書URL取得やAIトラブルシューティングのキー
- **製品名**: 例: リビングのエアコン
- **カテゴリ**: 例: エアコン
- **メーカー (Brand)**: 例: ダイキン
- **購入日 (Purchase Date)**: カレンダー選択、デフォルトは今日

#### 任意項目
- **シリアル番号 (S/N)**: OCRで取得できれば自動入力
- **購入価格**: 減価償却計算に必要
- **保証期間**: 1年、2年、3年、5年、7年、10年から選択
- **設置場所（部屋）**: 間取り図と連携するためのセレクトボックス
- **設置場所（詳細）**: 例: リビング南側
- **メモ**: 消耗品のストック場所や配線の注意点など

### 4. 登録処理

```
フォームバリデーション
    ↓
Device オブジェクトを作成
    ↓
DeviceService.addDevice() を呼び出し
    ↓
「家が調律されました」メッセージ表示
    ↓
画面を閉じてリストを更新
```

## UI/UXデザイン

### Thin Line Style
- 境界線: `0.5px` の極細ライン
- 余白: 贅沢に取った余白（padding: 20px）
- ボーダー: `#E5E5E5` の薄いグレー

### Intellectual UI
- **タイポグラフィ**: 
  - タイトル: `FontWeight.w300`, `letterSpacing: -0.5`
  - 入力フィールド: `FontWeight.w300`, `letterSpacing: -0.2`
- **入力フィールド**: 
  - ノイズを削ぎ落としたシンプルなデザイン
  - フォーカス時: 青い枠線（`#3b82f6`）

### AI自動入力のフィードバック
- AIが自動入力した項目には、キラリと光るような控えめなアイコン（`Icons.auto_awesome`）を表示
- 色: `Colors.amber[700]`

### 精密に調律中のアニメーション
- Leicaのレンズを調整しているような洗練されたアニメーション
- 外側の円に精密な目盛り（60分割）
- 回転アニメーション（2秒）
- 中央にカメラアイコン

## バリデーション

### 必須項目のバリデーション
- 型番: 空でないこと
- 製品名: 空でないこと
- カテゴリ: 空でないこと
- メーカー: 空でないこと
- 購入日: 自動的に今日が設定される

### エラーハンドリング
- 画像選択エラー: スナックバーでエラーメッセージを表示
- 登録エラー: スナックバーでエラーメッセージを表示
- OCR解析エラー: エラーを無視してフォームを表示（手動入力可能）

## データ永続化

### 現在の実装（モック）
- `DeviceService.addDevice()` でメモリ上のリストに追加
- `notifyListeners()` でUIを更新

### 将来の実装
1. **SharedPreferences**: 小規模データの場合
2. **ローカルDB (SQLite/Hive)**: 大規模データの場合
3. **API連携**: クラウド同期が必要な場合

## コンポーネント構成

### AddDeviceScreen
- 状態管理: `StatefulWidget`
- 画像選択: `ImagePicker`
- OCR解析: `OCRService`
- フォーム表示: `DeviceForm`

### DeviceForm
- 再利用可能なフォームコンポーネント
- バリデーション: `Form` + `TextFormField`
- 画像アップロードUI
- 日付選択: `showDatePicker`
- ドロップダウン: `DropdownButtonFormField`

### OCRService
- モック実装: 実際のOCR処理をシミュレート
- 将来の実装: Google ML Kit、Tesseract OCR、またはクラウドAPI

## テスト方法

1. メイン画面の「家電を追加」ボタンをタップ
2. 画像を選択（カメラまたはギャラリー）
3. 「精密に調律中...」アニメーションを確認
4. 解析結果がフォームに自動入力されることを確認
5. 必須項目を入力
6. 任意項目を入力（オプション）
7. 「登録する」ボタンをタップ
8. 「家が調律されました」メッセージを確認
9. デバイス一覧に追加されたことを確認
