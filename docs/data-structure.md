# データ構造定義書

## デバイス（Device）オブジェクト

### 基本情報
```json
{
  "id": "device-001",
  "name": "エアコン リビング",
  "modelNumber": "CS-ZX2811",
  "category": "エアコン",
  "manufacturer": "ダイキン",
  "purchaseDate": "2019-06-15",
  "purchasePrice": 180000,
  "yearsOwned": 5.2,
  "room": "living-room",
  "location": "リビング南側",
  "status": "active"
}
```

### メンテナンス情報
```json
{
  "maintenance": {
    "lastMaintenance": "2021-03-10",
    "nextMaintenance": "2024-03-10",
    "maintenanceInterval": 365,
```
